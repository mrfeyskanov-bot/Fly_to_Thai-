### 🚀 Начало работы:

**Шаг 1: Загрузить тему**
```
Внешний вид > Темы > Загрузить тему
Выберите папку fly-to-thai
```

**Шаг 2: Активировать**
```
Внешний вид > Темы > Активировать Fly to Thai
```

**Шаг 3: Настроить**
```
Внешний вид > Кастомизация:
- Загрузить логотип
- Заполнить контакты
- Создать меню
```

**Шаг 4: Добавить контент**
```
Туры > Добавить новый
Отзывы > Добавить новый
Специалисты > Добавить новый
```
