# Fly to Thai - WordPress Theme
## Туроператор по Таиланду

### Версия: 1.0.0

---

## Описание

Современная и отзывчивая WordPress тема для туроператора Fly to Thai. Включает полный набор функций для управления турами, отзывами, специалистами и контактной информацией.

### Возможности:

- ✅ Bootstrap 5 для адаптивного дизайна
- ✅ Кастомные типы постов (Туры, Отзывы, Специалисты)
- ✅ Кастомные таксономии для классификации туров
- ✅ Встроенная система контактов
- ✅ Интеграция с социальными сетями
- ✅ Полная локализация на русском языке
- ✅ SEO-оптимизирована
- ✅ Поддержка Custom Logo
- ✅ Шаблоны для всех типов страниц

---

## Требования

- **WordPress:** 5.0 или выше
- **PHP:** 7.4 или выше

## Установка

### Способ 1: Через админ-панель WordPress

1. Скачайте тему
2. Перейдите в **Внешний вид > Темы**
3. Нажмите **Загрузить тему**
4. Выберите файл темы
5. Нажмите **Установить**
6. Активируйте тему

### Способ 2: Через FTP

1. Распакуйте архив с темой
2. Загрузите папку `fly-to-thai` в директорию `/wp-content/themes/`
3. Перейдите в **Внешний вид > Темы**
4. Активируйте тему **Fly to Thai**

---

## Настройка

### 1. Логотип

1. Перейдите в **Внешний вид > Кастомизация**
2. Выберите **Идентичность сайта**
3. Загрузите логотип (рекомендуемый размер: 200x60px)

### 2. Контакты

1. В **Кастомизации** перейдите в раздел **Контакты**
2. Заполните:
   - Телефон
   - Email
   - Адрес

### 3. Социальные сети

1. В **Кастомизации** перейдите в раздел **Социальные сети**
2. Добавьте ссылки на:
   - VKontakte
   - Instagram
   - Telegram

### 4. Меню

1. Перейдите в **Внешний вид > Меню**
2. Создайте новое меню
3. Добавьте пункты (Главная, Туры, Контакты и т.д.)
4. Установите его как **Главное меню**

### 5. Виджеты

1. Перейдите в **Внешний вид > Виджеты**
2. Добавьте виджеты в боковую колонку
3. Заполните колонки подвала (Footer 1, 2, 3)

## Создание контента

### Добавление тура

1. Перейдите в **Туры > Добавить новый тур**
2. Заполните поля:
   - **Название** - название тура
   - **Описание** - подробное описание
   - **Изображение** - фото тура (рекомендуемый размер: 1200x800px)
   - **Направление** - выберите или создайте новое направление
   - **Уровень сложности** - выберите уровень
3. Нажмите **Опубликовать**

### Добавление отзыва

1. Перейдите в **Отзывы > Добавить новый отзыв**
2. Заполните:
   - **Название** - ФИО клиента
   - **Описание** - текст отзыва
   - **Изображение** - фото клиента (рекомендуемый размер: 300x300px)
3. Нажмите **Опубликовать**

### Добавление специалиста

1. Перейдите в **Специалисты > Добавить нового специалиста**
2. Заполните:
   - **Название** - ФИО специалиста
   - **Описание** - информация о специалисте
   - **Изображение** - профессиональное фото (рекомендуемый размер: 400x400px)
3. Нажмите **Опубликовать**

## Фильтры и хуки

### Хуки действия

```php
// После инициализации темы
do_action( 'flytothai_custom_setup' );
```

### Фильтры

Можно использовать стандартные WordPress фильтры:

```php
// Изменение количества постов на странице
add_filter( 'pre_get_posts', function( $query ) {
    if ( is_admin() || ! $query->is_main_query() ) return;
    
    if ( is_post_type_archive( 'tour' ) ) {
        $query->set( 'posts_per_page', 12 );
    }
} );
```

## Советы по оптимизации

1. **Изображения:**
   - Оптимизируйте изображения перед загрузкой
   - Используйте плагины для сжатия (Smush, ShortPixel)
   - Используйте формат WebP где возможно

2. **Кэширование:**
   - Установите плагин кэширования (WP Super Cache, W3 Total Cache)
   - Включите кэширование браузера

3. **SEO:**
   - Установите Yoast SEO или Rank Math
   - Заполняйте meta описания
   - Используйте правильную структуру заголовков

4. **Безопасность:**
   - Обновляйте WordPress и плагины
   - Используйте强 пароли
   - Установите плагин безопасности (Wordfence)

## Поддержка и помощь

### Часто задаваемые вопросы

**Q: Как изменить цвета?**
A: Отредактируйте файл `styles/custom.css` или используйте плагин для кастомизации CSS.

**Q: Как добавить новую страницу?**
A: Перейдите в **Страницы > Добавить новую** и заполните содержимое.

**Q: Как скрыть определенный элемент?**
A: Используйте CSS в файле `styles/custom.css` с помощью `display: none;`
